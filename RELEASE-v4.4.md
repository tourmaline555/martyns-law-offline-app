# Premivue v4.4 — Customer language polish

This is a **customer-facing language update only**, based on the v4.3 policy-generator release.

## Changes
- Remove GitHub, spreadsheet provenance, internal version history and database terminology from customer-facing explanation screens.
- Replace the home-screen storage notice with clear, concise information about offline use, backup and manual device transfer.
- Simplify the Saved assessments, Action tracker, saved-record and Policy Generator notices.
- Refresh About Premivue into plain-English help while keeping truthful disclosures about local data, password-encrypted backups, automatic sync, unencrypted browser storage and policy details outside archive backups.
- Update the service-worker cache version so devices can receive the new copy.

## No functional changes
All question IDs, scoring, scope logic, RAG calculation, policy outputs, action history, import/export formats and data storage keys are unchanged.

## Important limitation
This is not a cloud-synchronisation, encryption-at-rest or commercial licensing release. A customer must still export and securely keep an encrypted backup to protect against device/browser data loss.
