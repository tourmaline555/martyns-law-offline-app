# Premivue — Martyn's Law Readiness & Assurance

Offline-first assessment, RAG reporting, action tracking, dated audit trail and **tailored policy generator** and customer-ready help text.

The public GitHub Pages prototype is not the commercial Premivue website. Use the existing repo `tourmaline555/martyns-law-offline-app` for testing and Termux publishing.

Read `RELEASE-v4.4.md` for this copy-only release, and `PHONE-CHECKLIST-v4.4.md` for a quick device test. The underlying v4.3 policy-generator release notes remain available.

No network, server, external JavaScript libraries or government endorsement is required/claimed by the app itself. Records and policy inputs are stored in the local browser; download secure copies and keep them backed up.
