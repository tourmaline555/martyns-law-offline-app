# Android/Chrome release check — v3.9

This release passed Node-based tests, but graphical browser automation was blocked in the build environment. Before putting Premivue in front of customers, verify these behaviours on your own phone.

1. **Backup first** in your previous v3.8 version. Keep the JSON file safe; it is unencrypted.
2. Open v3.9 online and confirm the footer and all icons load; switch to airplane mode and reopen it.
3. Start a shop with 300 people, select no events, and finish all relevant readiness questions. For Q35 select No: verify it is an advisory High-priority action, not an Immediate critical failure.
4. On Q22 select N/A, try Next without a reason: it should stop you. Enter a 15+ character reason and retry.
5. Leave many questions unanswered and check that the result is **Unrated** below 80% valid coverage, not a high Green score.
6. On an applicable question select Not sure; verify the recommendation begins **VERIFY FIRST** rather than claiming an absence has been proven.
7. Create an event at a **separate location**; verify its event questions are not scored as part of the original premises, and scope instructs a separate check.
8. Check the results page for the top three actions, explanation of legal/advisory basis and links to SIA planning tools (links need connectivity).
9. Save an assessment, reassess it, and check the old record is read-only. New trends should not claim a comparable improvement across methodology/answer-set differences.
10. Export a full **encrypted audit backup**, save a password separately, then import into a separate browser profile or test device to verify recovery. A wrong password should be rejected.
11. Generate the management PDF and the full appendix; verify text is not clipped and the RAG and legal scope are clearly separated.

**Not included in this offline prototype:** cloud records, multi-user access control, tamper-evident/server-signed audit logs, Stripe licensing, or automatic official template completion. These require subsequent commercial backend work and independent review.
